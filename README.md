# Smart Outreacher — лендинг

Статический сайт без сборки и внешних зависимостей. Основан на согласованном HTML-лендинге. Тексты, цены, контакты и интерактивность сохранены.

## Состав

- `index.html` — структура и текст страницы.
- `assets/css/styles.css` — стили и адаптация для телефона.
- `assets/js/main.js` — проверка готовности и раскрытие описания метода.
- `assets/fonts/` — встроенные ранее шрифты, вынесенные в WOFF-файлы.
- `assets/fonts/LICENSE-URW.txt` — условия использования исходных URW Gothic.
- `assets/images/` — белый и темно-синий логотипы, символ и SVG favicon.
- `.nojekyll` — файл для размещения статических файлов через GitHub Pages.

## Размещение в GitHub

1. Распакуйте архив.
2. Загрузите **содержимое** этой папки в корень нужного репозитория. `index.html` и папка `assets` должны находиться рядом. Сохраните `.nojekyll`.
3. Включите GitHub Pages для выбранной ветки и папки, в которую загружены файлы. Для корня репозитория выберите корневую папку публикации.
4. Откройте адрес, который предоставит GitHub после публикации.

Все пути относительные: сайт может работать как в корне домена, так и в подпапке репозитория. Никакие ключи, Node.js, установка зависимостей или команда сборки не нужны.

## Просмотр локально

Откройте `index.html` в браузере. Для просмотра через локальный сервер из этой папки можно запустить:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Редактирование

Тексты, цены и контакты меняются в `index.html`. Почта используется в видимой подписи и ссылках `mailto:`; при замене проверьте все вхождения.

Основные цвета заданы в начале `assets/css/styles.css` через переменные `:root`. Логотип в шапке — `assets/images/logo-white.svg`.

Семейство шрифта в CSS называется Outreacher. Файлы содержат подмножества URW Gothic Book и Demi; исходный текст лицензии приложен. Шрифт подобран по характеру надписи логотипа и не является идентифицированным оригинальным шрифтом его генерации.

## Кнопки и данные

- Навигация и промежуточные кнопки ведут к разделам страницы.
- Кнопки связи открывают почтовое приложение. Телефон — ссылку `tel:`.
- Проверка готовности работает только в браузере, не отправляет и не сохраняет ответы.
- Формы отправки, аналитика, база данных и серверная часть отсутствуют.

## Проверка перед публикацией

Проверены существование файлов, относительные ссылки на ресурсы, цели якорей и синтаксис JavaScript. Визуальная проверка в браузере в этой среде не проводилась. Перед публикацией откройте страницу на компьютере и телефоне, проверьте шрифт, логотип, кнопки и отсутствие горизонтальной прокрутки.
